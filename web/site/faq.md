# 常见问题

## 需要安装吗？

不需要。下载单个 `AppTimer-v3.exe`，双击就能用，不写注册表（可选的开机自启只写 `HKCU` 一个键），也不需要管理员权限。

首次启动会把运行库解包到系统临时目录，等一两秒就出来了；这是单文件版的代价，换来的是下载下来就一个文件、不用解压。

## 数据保存在哪里？

默认在 `%LOCALAPPDATA%\AppTimer\程序使用记录\`，用 SQLite 存（`v3.db`）。设置页可以把位置改到任意目录，例如 `D:\我的数据`。

旧版本（v1 / v2）把数据放在桌面的 `程序使用记录` 文件夹，升级后可以在设置页「导入旧版数据…」直接导进来。

## 换电脑怎么迁移？

设置页「打开」定位到数据目录，把整个 `程序使用记录` 目录复制到新电脑，再在设置页把位置指过去（或者覆盖默认位置的同名目录）。

## 支持导出什么格式？

PDF。概览页右上角「导出 PDF」生成 `报告_YYYY-MM-DD.pdf`，包含今日明细、累计排行和分类汇总。CSV 导出在 v3 已取消。

## 为什么有些程序没有被记录？

AppTimer 按「前台窗口」计时，所以：没有窗口的后台服务不会出现；同一程序开了多个窗口会合并成一条记录；UWP 系统应用（计算器、照片、设置等）会穿透到真实进程，可以正常记到。

## 需要联网吗？

不需要。程序完全离线，数据只存本机，唯一的网络动作是你自己点下载。

## 内存为什么比上一代小这么多？

上一代用 WebView2 承载 Vue 页面，光浏览器子进程就要 300MB 上下；现在界面由 Python 直接画在窗口画布上，整包实测常驻约 50MB。

## 关掉窗口后程序还在？

这是设计行为：点 X 收进托盘继续计时。右键托盘图标可以「显示窗口」或「退出」。

## 杀毒软件报毒？

PyInstaller 打包的未签名 exe 容易被误报，可以加白名单，或者直接从 [GitHub 仓库](https://github.com/zjoachim/apptimer) 拿源码用 Python 3.14 运行。

## v1、v2、v3 有什么区别？

详见[版本区别](/guide#版本区别)：v3 是当前版本（原生窗口、9 个页面、约 50MB），v2 是基于 WebView2 的上一代，v1 是更早的单文件 tkinter 版本。

## 下载时提示「通常不会下载」怎么办？

这是 Edge 对未签名 exe 的正常安全提示，不是病毒。点弹窗的「保留」→「仍然保留」即可。
