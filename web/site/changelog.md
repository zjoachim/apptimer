# 更新日志

## v3.0

**发布日期**：2026-11

界面从 WebView2 + Vue 换成 Python 直接绘制，常驻内存从约 360MB 降到约 50MB。

### 架构

- 原生窗口 + 自绘界面：Pillow 画布、形状 2 倍超采样、文字直绘，按系统 DPI 等比缩放
- 数据层换成 SQLite（应用 / 天 / 小时三张表），跨天、跨小时自动钳制
- 采集改成事件驱动：`SetWinEventHook` 收到前台切换立即结算，1 秒节拍兜底
- 打包成单文件（onefile），下载下来双击即用；另提供目录版以获得更快的启动

### 新增

- 9 个页面：概览、累计、图表、时段、趋势、分类、历史、番茄钟、设置
- 时段页：今日 24 小时分布 + 最近 7 天 × 24 小时热力图
- 番茄钟：25 / 5 分钟，每 4 个长休息 15 分钟，到点托盘提醒
- 每日目标：概览页进度条（未超出绿、超出红），超预算每天提醒一次
- 应用图标与别名：从 exe 提取图标，右键改名全站生效
- 图表动画：饼图扫入、柱子从基线生长、折线从左向右绘制
- 自定义数据位置：数据目录可搬到任意位置，迁移时复制并逐文件校验
- 导入旧版数据：v2 的桌面 JSON 可以直接导入
- 主题：亮色 / 深色切换，支持自定义主题色
- 采集参数可调：空闲阈值、保存间隔、数据保留
- UWP 应用可以正常记录；有声即视为在看

### 变更

- 数据默认位置从桌面改成 `%LOCALAPPDATA%\AppTimer\程序使用记录\`
- CSV 导出取消，只保留 PDF
- 托盘图标改为原生实现，关窗后收进托盘继续采集

### 已知限制

- 单文件版首次启动要解包运行库，慢一两秒
- 只统计有窗口的前台程序，后台服务不计

## v2.0

**发布日期**：2026-05

### 架构变更

- 前后端分离：Python HTTP 服务 + Vue 3 前端
- Edge 无边框窗口：`--app` 模式启动，界面干净无地址栏
- 本地 HTTP 服务：`127.0.0.1:17777`

### 新增功能

- 7 个标签页：概览、累计、图表、趋势、分类、历史、设置
- ECharts 可视化：饼图 + 柱状图
- 趋势分析：近 7 天使用对比
- PDF 导出：带图表的报告
- 三级降级进程检测：提高窗口识别准确率
- 单实例互斥：防止重复启动

### 技术栈

- 前端：Vue 3 + ECharts + Tailwind CSS
- 后端：Python HTTP Server + Windows API
- 打包：PyInstaller one-file 模式

## v1.0

**发布日期**：2026-05

### 功能

- 自动追踪 Windows 程序使用时长
- 程序分类标签（工作/学习/娱乐/社交/开发/设计/其他）
- 日/周/月报表自动生成
- 饼图 + 柱状图可视化（tkinter Canvas）
- 每日使用目标设定 + 超时提醒
- 休息提醒（连续使用 45 分钟）
- CSV 导出
- 深色模式（自动跟随 Windows 主题）
- 系统托盘 + 后台运行
- 开机自启动
