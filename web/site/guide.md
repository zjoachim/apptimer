# 使用指南

## 安装与启动

AppTimer 是便携式应用：不用安装、不用管理员权限、不写注册表（除非你自己打开「开机自启」）。

1. 下载 `AppTimer-v3.exe`（约 31MB）
2. 放到任意文件夹，双击运行

首次启动会把运行库解包到系统临时目录，需要一两秒，之后就快了。关闭窗口不会退出程序，它会收进托盘继续计时；要真正退出，用顶栏的「退出」或托盘右键菜单。

::: tip 单文件版 / 便携目录版
单文件版 `AppTimer-v3.exe` 双击即用，不需要解压。如果你更在意启动速度，也可以下 `AppTimer-v3.zip`：那是目录版，解压后运行里面的 `AppTimer.exe`，启动不需要解包。
:::

::: tip 系统要求
Windows 10 与 Windows 11 都可以。程序是原生窗口，不依赖浏览器或 WebView2。
:::

## 界面概览

顶栏右侧是「亮色 / 深色」切换和「退出」，下面一行是 9 个页面：

| 页面 | 说明 |
|---|---|
| 概览 | 今日总时长大数字、每日目标进度、分类胶囊、应用列表（图标 + 占比 + 进度条） |
| 累计 | 跨天排行：今日 / 累计 / 占比 / 进度条，滚轮翻页 |
| 图表 | 环形图与柱状图，今日 / 累计两种口径，默认取前 10 名 |
| 时段 | 今日 24 小时分布，以及最近 7 天 × 24 小时热力图 |
| 趋势 | 单个应用最近 14 天的折线，点应用名换一个看 |
| 分类 | 每个程序归到哪个分类，点一行循环切换 |
| 历史 | 最近 30 天列表，选中某天看当天明细 |
| 番茄钟 | 25 分钟专注 / 5 分钟休息，到点用托盘气泡提醒 |
| 设置 | 数据位置、每日预算、主题色、采集参数、旧数据清理 |

## 计时与记录

- **事件驱动**：前台窗口一换就立即结算，另有 1 秒节拍兜底，不是定时轮询前台窗口。
- **UWP 应用**：计算器、照片、设置这类系统应用会穿透到真实进程，能正常记到。
- **空闲判定**：超过 120 秒没有键鼠输入就停表；这时如果系统在出声（在看视频），继续计时；连续出声超过 2 小时按挂机处理。
- **休眠 / 合盖**：节拍中断超过 5 秒的这段时间不计入。
- **不记录自己**：AppTimer 自己的窗口不计时。
- **单实例**：同时只允许一个实例在跑，避免重复计时。

## 数据与报表

### 数据位置

默认数据在：

```
%LOCALAPPDATA%\AppTimer\程序使用记录\
```

设置页可以把「位置」改到任意目录，比如 `D:\我的数据`。AppTimer 只在位置下自建的 `程序使用记录` 子目录里写东西，位置里的其它文件一概不碰。

换位置时会把 AppTimer 自己的数据复制到新位置并逐文件校验，原目录保留；确认没问题后可以在设置页「清理旧数据」。

### 导入旧版数据

以前用过桌面版 `程序使用记录` 的话，设置页「导入旧版数据…」可以把那些 JSON 直接读进来：跨零点的会话会拆到对应的小时桶，重复导入不会翻倍。

### 导出报告

概览页右上角「导出 PDF」会在数据目录生成 `报告_YYYY-MM-DD.pdf`，内容是今日明细、累计排行和分类汇总。

::: info 关于 CSV
上一代的 CSV 导出已经取消——日常数据在界面里就能看，需要明细可以直接查数据库。
:::

### 数据保留

默认永久保留。设置页可以改成保留 N 天，改小之后会立刻清理超额记录。

## 分类与别名

「分类」页每行一个程序，点一下按 未分类 → 工作 → 学习 → 娱乐 → 社交 → 其他 循环切换，直接写库；胶囊上的小圆点用分类配色标记。

右键某一行可以改名：把 `wechatappex.exe` 改成「微信」，之后所有页面都显示这个名字。

## 番茄钟与每日目标

**番茄钟**：25 分钟专注、5 分钟休息，每 4 个番茄后长休息 15 分钟。开始 / 暂停 / 重置 / 跳过都在页面上，切到别的页面倒计时照常走，到点用托盘气泡提醒。

**每日目标**：设置页填一个目标时长后，概览页大数字下方会出现进度条——没超出是绿色，超出后整条转红，剩余或超出精确到分钟。超出当天只提醒一次。

## 设置与自启动

- **开机自启**：写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员；
- **主题**：顶栏切换亮色 / 深色；设置页可以指定一个自定义主题色；
- **采集参数**：空闲阈值（默认 120 秒）、保存间隔（默认 5 秒）改完重启生效；数据保留改小立即清理；
- **托盘**：右键托盘图标可以「显示窗口」或「退出」。

## 版本区别

当前版本是 **v3**（原生窗口 + 自绘界面）。仓库里还留着两代旧实现：

| | v1 | v2 | v3（当前） |
|---|---|---|---|
| 界面 | tkinter 单文件 | Vue 3 + ECharts，Edge 无边框窗口 | Python 自绘画布，原生窗口 |
| 依赖 | 无 | WebView2 / Edge | 无，单文件双击即用 |
| 页面 | 4 个 | 7 个 | 9 个 |
| 导出 | CSV | CSV + PDF | PDF |
| 数据位置 | 桌面 `程序使用记录` | 桌面 `程序使用记录` | `%LOCALAPPDATA%\AppTimer`，可自定义 |
| 系统 | Win10 / 11 | Win11 推荐 | Win10 / 11 |

v3 常驻内存约 50MB，v2 因为要跑一个 WebView2 子进程，实测约 360MB。

下载入口：

- **v3（当前，单文件）**：`AppTimer-v3.exe`
- **v3 便携目录版**：`AppTimer-v3.zip`（解压后运行，启动更快）
- **v2**：`AppTimer-v2.exe`（Win11）
- **v1**：`AppTimer-v1.exe`（Win10）
- 历史版本都在 [GitHub Releases](https://github.com/zjoachim/apptimer/releases)
