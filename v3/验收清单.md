# 验收清单

> 打包版：v3/dist/AppTimer/AppTimer.exe（目录版，整包分发）。开发版：v3/启动 v3.bat。
> 两者共用同一份数据与配置（%LOCALAPPDATA%/AppTimer + 你的数据目录），单实例互斥体保证不会同时跑两个。

## 一、自动化（最先跑，5 秒）

```bat
cd /d D:/apptimer
py -3.14 v3/tools/run_tests.py
```

期望：`5/5 通过`，退出码 0。

| 脚本 | 覆盖 |
|---|---|
| selftest_db | 写入累加、天 86400 / 时 3600 钳制、累计不受钳制 |
| selftest_dir | 位置=父目录、数据目录=位置/程序使用记录、恢复默认、无关文件不计入 |
| selftest_import | v2 JSON 导入（跨零点会话切小时桶）、幂等、分类/累计写入 |
| selftest_migrate | 目录迁移复制+校验、四种拒绝场景、purge 白名单 |
| selftest_window | 8 个 tab 切换、图表切换、趋势翻页、历史选中、分类写入复原、滚动、关窗进托盘、目标解析/写入/复原、超额只提醒一次、PDF 导出 |

页面不弹窗预览：`py -3.14 v3/tools/preview.py 杂/v3-proto/x.png 时段`

## 二、手动验收（3 分钟）

### 1. 趋势页选应用（30 秒）
1. 点「趋势」
2. 点应用名 → 弹下拉列表
3. 滚轮 → 列表翻页
4. 点另一个应用 → 折线立刻切换
5. 点面板外 → 关闭

不合格：点了没反应 / 关不掉 / 折线没变。

### 2. 时段页（20 秒）
点「时段」：今日 24 小时柱 + 最近 7 天 x 24 小时热力。
对账：下午用得多，14-18 点就该最亮。

### 3. 每日目标 + 超额提醒（60 秒，最容易验）
1. 设置 → 「每日目标」→ 设定… → 输入 `10s`
2. 回概览：大数字下方应出现暖色「每日目标 10s · 已完成 XXX% · 已超出 …」+ 进度条
3. 等 1-2 秒：托盘弹一次气泡「已超出每日目标」
4. 再等：不应再弹（每天一次）
5. 回设置改回 `4h` 或填 `0` 取消

不合格：设完概览没变化 / 气泡不弹 / 一直重复弹。
注：气泡受 Windows 通知设置影响，关掉时会只进通知中心。

### 4. 设置页其余项（可选）
- 开机自启：第一次点会弹 Windows 的「允许开机启动」确认
- 导入旧版数据…：选「桌面/程序使用记录」→ 状态行显示「已导入 N 天 / N 条会话 / N 个小时桶」，可重复执行不翻倍
- 打开：开资源管理器到数据目录
- 旧数据块：只有切换过位置才出现；清理时删空目录

### 5. 顶栏与托盘（10 秒）
- 导出 PDF：数据目录出现 报告_YYYY-MM-DD.pdf
- 退出：真正退出；点窗口 X：收进托盘，采集继续；托盘右键「显示窗口 / 退出」

## 三、打包版验收

```bat
v3/build.bat
v3/dist/AppTimer/AppTimer.exe --selftest D:/report.txt
```

自检文件应为：

```
页面模块导入: ok (6 个)
SQLite: ok，应用 N 个
图标提取: ok (32, 32)
PDF 导出: True (...)
frozen: True
```

（打包版还会报一行 `pid 文件写入失败: PermissionError`，只影响开发脚本定位窗口，不影响功能。）

## 四、回归重点

- 采集在写库：概览数字随时间增长（空闲 2 分钟后暂停是正常行为）
- 关窗进托盘后采集继续：关 1 分钟再开，今日总数应增长
- 切换数据位置后：旧目录标「旧数据」，采集线程重启
## 五、v3 增量功能（2026-11-14 之后加）

- **白线**：窗口顶端那条 1px 白线来自 `shell.draw_shell` 里一句无填充无描边的 `f.rect(0,0,W,44)`（Pillow 会沿边画白线）。已在 `Frame.rect` 加跳过保护，验收：窗口顶端与标题栏无亮线。
- **今日预算**：概览页第二行；未超出绿色 `(86,200,124)`，超出纯红 `(255,0,0)`；剩余/超出精确到分钟；设置页可设定、可开关；超预算弹一次托盘气泡（跨进程每天一次）。
- **番茄钟**（独立一栏）：25 分钟专注 / 5 分钟休息 / 每 4 个长休息 15 分钟；开始·暂停·重置·跳过；今日完成数；到期弹气泡（在任何 tab 下都生效）。验收：点开始 → 倒计时每秒递减；到 0 自动切到休息并弹气泡。
- **v2 三个采集参数**：空闲阈值（默认 120 秒）/ 保存间隔（默认 5 秒）/ 数据保留（0 = 永久）。前两个重启生效；数据保留改小会立即清理旧记录。
