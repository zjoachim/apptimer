## 实测

| 项 | 数值 |
|---|---|
| v2（pywebview + WebView2，真实页面） | 363 MB |
| **v3（窗口 + 概览页，真实数据 18 项）** | **44.5 MB** |

## 打包

```bat
v3\build.bat
```

产物 `v3\dist\AppTimer\`（约 63 MB，含 `_internal`），**整个文件夹**压缩分发，双击 `AppTimer.exe` 运行。

- 用的是 **onedir**（目录版）：启动快，不做运行时自解压，杀软敏感度低
- **onefile 在本机不可用**：PyInstaller 启动阶段报 `Could not create temporary directory!`，连 2 行的最小 Tk 程序也一样，属于环境问题而非代码问题
- 打包后自检：`AppTimer.exe --selftest D:\report.txt` 会把页面导入/SQLite/图标提取/PDF 导出结果写进文件（windowed exe 没有控制台）
- 已知小问题：打包版写 `%LOCALAPPDATA%\AppTimer\v3.pid` 会 PermissionError（被静默忽略；只影响开发脚本定位窗口，不影响功能）

## 运行

```bash
py -3.14 v3/run.py                          # 启动窗口
py -3.14 v3/tools/preview.py out.png 图表    # 无窗口渲染任意页面，便于迭代
```

## 采集

- **触发**：`SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 收到切换立即结算；另有 1 秒节拍兜底（不是轮询前台窗口）
- **累加**：以秒为粒度记到当前前台应用；应用切换、退出时强制落盘，平时缓冲 5 秒一写
- **UWP**：进程名是 `ApplicationFrameHost` 时用 `EnumChildWindows` 挖真实子进程，最多重试 2 次
- **空闲**：超过 120 秒无输入 → 查默认播放设备峰值（Core Audio），有声则继续计时；持续有声超过 2 小时判为挂机停表
- **休眠/待机**：节拍间隔超过 5 秒视为系统休眠，这段时间不计
- **不记录自己**：跳过自身 PID、与本体同解释器的进程、以及 `apptimer.exe`（v2）
- **单实例**：`Local\AppTimerV3_SingleInstance` 互斥体，第二个实例弹提示后退出，避免双份计时
- **可测**：`V3_IDLE_THRESHOLD` 环境变量可覆盖空闲阈值（测试用）

## 内存账（实测，`%LOCALAPPDATA%` 下运行）

| 组成 | 增量 | 累计 |
|---|---|---|
| Python 解释器 | 14.8 MB | 14.8 |
| + PIL | +8.4 | 23.2 |
| + tkinter / canvas | +10.3 | 33.5 |
| + 一张 900×680 图像 | +8.2 | 41.7 |
| + 托盘 | +0.4 | 42.1 |
| + sqlite3 | +0.2 | 42.3 |

完整应用实测 **52.4 MB**（60 秒采样稳定，SS=2.0）。省内存的三个决定：
- 形状层超采样 **2.0 → 1.5**（4 倍放大下几乎看不出差别，帧缓冲 7.3MB → 4.1MB）
- 托盘自己用 ctypes 写，不用 pystray（pystray 实测多吃 2.2MB）
- `fpdf2` 惰性导入（常驻会带进 fontTools，实测多吃约 40MB，只在导出瞬间占用）

## 动效（对齐 v2 的 ECharts 默认动画）

v2 的动效来源是 ECharts 默认参数：`animationDuration=1000ms`、`animationEasing=cubicOut`；趋势页是 `smooth: true` 的平滑曲线。
（`style.css` 里的 `.fade-*` 是死代码，没有任何组件用 `<transition name="fade">`，所以 v2 切 tab 其实没有淡入——v3 也不做。）

| 页面 | 动效 |
|---|---|
| 图表 · 饼图 | 从 12 点方向顺时针扫入，标签在最后 45% 淡入 |
| 图表 · 柱状图 | 柱子从基线生长，数值标签在 85% 后出现 |
| 累计 | 行按 70ms 错位淡入，进度条同步生长 |
| 趋势 | 平滑曲线（Catmull-Rom 采样）从左向右绘制，圆点逐点出现 |

驱动方式：`theme.anim_start(state)` 打时间戳 → 窗口在动画期间以 `after(1)` 连续重绘，动画结束自动停（实测 22fps、结束后 0 次重绘）。

## 命名约定（重要）

`v3` 是开发者内部代号，**用户界面里不出现**：窗口标题就是「程序使用时间追踪器」，顶栏只有「AppTimer」，PDF 落款「由 AppTimer 生成」。
内部标识（文件名 `v3.db` / `v3-settings.json` / 互斥体 `AppTimerV3_SingleInstance` / 环境变量 `V3_*`）保留 v3，用于区分数据与调试。

## 细节约定

- 胶囊按钮里的文字一律用 `Frame.text_centered(cx, cy, ...)`——按字体墨迹盒居中，不用「字顶 y + 固定偏移」，避免上下偏 1-2px。
- 窗口标题栏走 DWM 深色模式（属性 20，回退 19），和深色主题一致。
- 图标：深色圆底 + 白色表盘（`tray.icon_image`），浅色/深色标题栏和托盘上都看得清。
- 应用启动会把 PID 写进 `%LOCALAPPDATA%\AppTimer\v3.pid`，外部脚本据此定位窗口（中文标题在 PowerShell 5.1 下会因编码问题匹配失败）。

## 页面协议

`app/ui/pages.py` 是注册表：除概览/设置外的页面走统一协议，各自一个文件、互不干扰。

```
draw(f, snap, state)                   # 画整页（顶栏和 tab 由壳负责）
on_click(x, y, state, snap) -> bool    # 返回 True 表示已消费，窗口重绘
on_wheel(delta, state, snap) -> bool
```

调试入口：`V3_START_TAB=chart|trend|history|cumulative|settings` 可直接以某页启动（截图/演示用）。

## 数据位置

设置里选的是**位置（父目录）**，v3 在该位置下自己新建 `程序使用记录\` 存放数据：

- 默认位置：`%LOCALAPPDATA%\AppTimer\` → 数据在 `%LOCALAPPDATA%\AppTimer\程序使用记录\`
- 自定义位置：例如选 `C:\Users\Joachim\Desktop\chaos` → 数据在 `...\chaos\程序使用记录\`，位置里的其它文件一概不碰
- 换位置：把当前数据目录里 **AppTimer 自己的条目**（`YYYY-MM-DD` 日期目录、5 个 json、`v3.db` 及 WAL、周报/累计导出）复制过去并逐文件校验，原目录保留；数据为空时直接切换不复制
- **打开数据目录**：设置页「打开」按钮直接调起资源管理器
- **清理旧数据**：只删 AppTimer 自己的条目；删完目录变空时**连目录一起删掉**，目录里还有别的文件则保留并提示
- 配置文件：`%LOCALAPPDATA%\AppTimer\v3-settings.json`（删掉它等于恢复默认）
- v3 与 v2 完全隔离：不读、不写、不迁移 v2 的 `程序使用记录`

## 约束

1. **只读**：v3 不写 `程序使用记录`；将来接管采集前，必须先做单实例互斥与数据迁移。
2. **内存**：`PhotoImage` 必须替换复用而非累积；图表区不做 alpha 合成；静态层缓存、只重绘变化区域。
3. **视觉**：所有圆角/渐变走 `theme.Frame`，页面里不直接调 `ImageDraw`。
